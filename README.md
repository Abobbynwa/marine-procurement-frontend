# MarineProcure Frontend

A React frontend MVP for a marine company procurement management system.

## Current Scope

- Role-based login UI
- Admin/procurement dashboard
- Purchase requests
- Vendor management
- RFQ management
- Quotation comparison
- Purchase orders
- Reports
- Settings/profile page

## Tech Stack

- React
- Vite
- React Router
- Plain CSS

## Run Locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:5173
```
